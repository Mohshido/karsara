
Contributing to Karsara

We welcome your contribution to the development of Karsara.
Karsara is an open source project from the Mohshid ecosystem and our goal is to develop an accessible tool for blind and visually impaired users.

How to contribute?

1. Create an Issue

Before starting a major change, first create an Issue and explain:

- What is the problem?

- What do you suggest?

- Why is this change useful?

For bugs, include steps to reproduce the problem and, if possible, system information.

2. Create a Branch

Please do not work directly on "main".

Create a separate Branch for each change.

Example:

feature/pdf-reader
bugfix/keyboard-shortcut
docs/update-readme

3. Commit your changes

Develop the code according to the existing project structure and standards.

Avoid making unrelated changes in the same Branch.

4. Create a Pull Request

Once you are done, create a Pull Request to "main".

Indicate in the Pull Request description:

- What has changed?

- What issue has been fixed?

- How did you test it?

- If applicable, indicate the associated Issue with "Closes #NUMBER".

5. Code Review

All changes are reviewed before being pushed to "main".

The Pull Request must receive at least one Approval.

Maintainers may request additional changes or fixes.

6. Merge

Once the Review is approved and the issues are resolved, the Pull Request can be merged to "main".

Important Rules

- Avoid pushing directly to "main".

- Use a separate Branch for each change.

- Make small, specific changes.

- Test your changes before submitting the Pull Request.
- Never commit sensitive information, passwords, API keys or private files.
- If you find a security bug, do not publish it publicly in an Issue and contact the project maintainers first.
