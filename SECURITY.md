# Security Policy

## Reporting a Security Vulnerability

Karsara security is important to us.

If you find a security vulnerability or serious security issue in Karsara, please do not publish it publicly in a GitHub Issue.

Please discuss the issue with the project maintainers before publishing it publicly so that they can investigate and fix the issue.

In your report, please provide the following, if possible:

- Description of the vulnerability

Steps to reproduce the issue

Affected Karsara version

Operating system and runtime environment

- Screenshots, logs, or code samples if needed

- Potential impact of the vulnerability

## Security Issues

Please do not publish sensitive information such as:

- Password

- API Key

- Access Token

- User personal information

- Private files

in a public GitHub Issue or Pull Request.

## Scope

This security policy applies to the Karsara project and the code in Mohshid's official repository.

## Supported Versions

Currently, the security focus of the project is on the latest released version of Karsara.

Older versions may no longer receive security support.
